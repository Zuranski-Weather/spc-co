# SPC Outlook Viewer
Mike Zuranski - Zuranski Weather LLC (2026)

Small single-file static app to visualize NOAA/SPC convective outlook shapefiles.
Available at: https://zuranskiweather.com/tools/spc-co/

Self-Host Quick Start

1. Open the `index.html` file in a browser (no build required).
2. Use the Day dropdown to fetch live SPC outlooks, or drag a shapefile ZIP onto the map.
